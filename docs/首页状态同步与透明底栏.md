# 首页状态同步与透明底栏

日期：2026-10-19。版本：0.5.1+18。

## 调整

- 导航卡使用确认派发后后端返回的任务名称、地址及回执；地图搜索/收藏地点有名称且确认结果坐标一致时保留其展示名称。仅选点、解析、取消确认都不更新首页已发送目的地。
- 新增独立Keychain任务引用，按服务域名、登录账号和设备隔离。仅存任务ID及可选展示名称，恢复后重新GET任务详情；网络失败显示“状态待核对”，403/404不继续展示旧任务。不改原会话/连接存储，不上报车机状态、不消费车机任务。
- 老版本已丢失的任务ID无法凭空恢复；后台没有手机“最新导航目的地”查询接口。更新后再次明确确认派发的任务才会建立可恢复引用。卡片表示上次发送及任务回执，不能证明NAVITIME正在导航，也不能展示其他客户端未同步的实际导航终点。
- 音乐卡根据车机状态中的曲目ID补查后端元数据，展示曲名、艺术家、已上报进度/总长及中文播放状态。只有真实状态报告改变播放状态，命令ACK不当作起播。缺少元数据显示“曲名暂不可用”，不把ID伪装曲名；后端自身只提供占位标题时客户端无法还原真实歌名。
- 修复WebSocket写入曲目占位值阻止后续查详情的问题；抑制重复查详情，失败后延迟重试，身份/设备/曲目变化后的迟到结果丢弃。心跳/快照过期显示“状态待更新”，不本地模拟进度增长。
- 底栏降低填充与选中胶囊的不透明度，保留有界模糊、细边框、拖动吸附和减少透明度/高对比辅助回退。保留四Tab状态、安全区、键盘策略和首页3D手势。仍是Flutter自绘玻璃，并非Apple原生Liquid Glass或其折射动画；不保证WKWebView/MapKit平台视图背后可被相同滤镜采样，内容与底栏仍保持安全区隔离。
