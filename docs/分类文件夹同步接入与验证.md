# iOS 分类文件夹同步接入与验证

版本：0.4.2+14；日期：2026-10-18。仅修改 `ios_app`，不编辑后端、车机或共享契约。

## 已实现

- 行驶页收藏抽屉通过动态账号会话访问 `/api/v1/favorite-folders` 与 `/api/v1/favorites`，无本机分类数据库或静态替代。
- 单层分类新增、重命名、删除；右滑分类行显示管理按钮，菜单同样可用。右滑本身不删除；删除二次确认明确“所有地址保留并移回未分类”。
- 区分全部、未分类及具体分类；分类显示服务端地址数量；地址和分类按服务端 `has_more` 分页，去重并阻止重复并发分页；地址滚动到底部自动更多，另有显式加载按钮。搜索显式提交到服务端，分类内仅搜索该分类地址，全部视图同时搜索分类名与地址。
- 地址新增、编辑可选择服务端分类，亦可菜单移动至分类或未分类。PATCH 省略 `folder_id` 保留现归属，显式 `null` 移回未分类；名称/地址长度对齐后端128/512字，分类名1～64字。只接收有限、合法WGS84坐标。
- 删除分类刷新分类、计数和地址，选中分类已删除时切至未分类。筛选分类遇404回退全部并刷新。重复DELETE404视为目标已不存在并刷新；409提示重名并刷新；401沿现有登录会话失效流程，403提示权限问题，不套用旧Token或越权。
- POST无自动重试；网络超时/断线等结果不确定时阻止本编辑器再次保存，要求关闭并刷新核对。保存失败不提示成功。PATCH也不后台重放。
- 账号或HTTPS域名变化立即清空当前列表、筛选和搜索；每次请求固定原身份/域名，迟到响应不得污染新账号。旧编辑/确认/移动窗口显示会话切换提示且不可继续操作；旧请求401不注销新域名会话。
- 现有MapKit地点搜索/前台定位、抽屉透明圆角、玻璃Tab、3D固定pitch、Keychain及“解析→候选→明确确认派发”保留。本轮收藏操作不触发导航或音乐。
