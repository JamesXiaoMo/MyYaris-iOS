# 音乐主页布局调整

版本：0.5.0+17。

- 音乐主页移除旧搜索输入框、说明副标题和播控卡；右上角按钮打开独立搜索页，保留在线、本地和缓存曲库搜索及可播性检查。
- 顶部展示后端返回的网易云头像、ID、会员类型，管理员可打开既有登录/切换账号流程；不会自动注销、扫码或导入凭据。普通账号隐藏管理员私人资料。
- 后端只有会员类型码，没有到期时间，因此剩余天数显示“未提供”，没有用凭据更新时间推算。
- 收藏音乐入口打开既有“我喜欢的音乐”列表，不伪造其他未接入的网易云歌单。
- 右下角黑胶唱片显示当前曲目封面，点击进入独立播放页，进度、软件音量、循环及执行回执继续使用原播控逻辑。播放页也可进入搜索。
- 只有新鲜车机心跳与有效播放状态均为playing时旋转；暂停保持角度，过期/未知状态停转，隐藏Tab、后台和减少动态效果时不转。不将指令接受回执当作已经起播。
- 头像/封面不携带后端凭据；仅允许HTTPS，可信网易云图片HTTP地址升级为HTTPS，失败时使用占位图。
- 账号/域名变化清空资料与搜索结果，丢弃迟到响应，旧身份页面不可继续显示或操作。

检查：76项测试通过，静态检查通过，签名Release构建通过。尚未完成该音乐布局的真机页面截图/安装验收；发布已因公开前隐私清理暂停。本轮未发送播放、音量、导航或登录写请求。

只读真机验收入口为 `tool/music_layout_acceptance.dart`，仅查账号状态、搜索及打开页面。已有喜欢歌单和阶段1验收脚本已适配新页面入口，但没有在本轮运行真实播放验收。

公开仓库不包含真实页面截图；本机验收产物只写入被忽略的私有目录。隐私改动后77项测试与签名Release构建亦通过；记录见[隐私清理与公开准备](隐私清理与公开准备.md)。
