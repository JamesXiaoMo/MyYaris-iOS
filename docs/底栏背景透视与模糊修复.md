# 底栏背景透视与模糊修复

日期：2026-10-19。版本：0.5.2+19。

原问题：底栏虽然已半透明，但Scaffold仍给它保留独立区域，下层页面没有绘制到它后面。因此能透出的只是背景色，而不是页面内容；继续降低颜色透明度无法解决。

本次改为Scaffold.extendBody，让页面实际绘制在浮动胶囊后面，保留局部ClipRRect/BackdropFilter，不新增原生Tab桥接或第三方依赖。减弱外部黑色阴影。底栏采样真实下层绘制内容，不采用复制截图或静态模糊图。平色下层不会产生明显纹理，内容滚动到后面时才会有相应变化。

首页、收藏抽屉、音乐和设置将Scaffold提供的底栏遮挡高度计入滚动末尾留白，允许内容经过胶囊后方，同时能把最后一个按钮滚动到胶囊上方。音乐唱片保持在底栏上方。行驶抽屉使用可见区域比例到实际延伸高度的映射，保留原来的可见展开高度及吸附档位；地图仍只占抽屉上方区域，不修改原生MapKit手势策略。键盘隐藏底栏、辅助功能实底回退、四Tab状态及登录门禁保持。

测试包括实际渲染像素测试：改变底栏后的红/蓝下层后，胶囊内采样像素随之改变；页面几何测试验证抽屉确实延伸过胶囊底部、列表有可滚动避让空间、唱片不被遮挡。测试还回归点击、拖动松手一次提交、取消拖动、触控尺寸、辅助选项、键盘与登录隔离。

真机0.5.2+19只读验收已完成：在真实iPhone上注入Flutter点击/拖动事件，四页打开成功，拖动期间不切页、松手切换一次。完整行驶页截图已实际打开检查，抽屉背景连续延伸到底部，原独立黑底区域消失。此结果不等于本轮重新验证过用户物理地图拖动，也不宣称苹果原生Liquid Glass折射效果；没有发送播放/导航或账号写请求。
