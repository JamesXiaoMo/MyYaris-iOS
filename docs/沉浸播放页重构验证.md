# 沉浸播放页重构验证

版本：0.5.7+25。按用户确认的概念图实现Flutter真实控件，未用整张UI图片覆盖屏幕，未添加第三方渲染依赖。

## 视觉与入口

- 独立全屏播放路由：MY YARIS标题、下拉返回、选项菜单；底部不显示四Tab，返回后保留音乐页与其余Tab状态。
- 大黑胶唱片、静态唱针、真实封面和模糊背景；唱片随实际playing且新鲜心跳旋转，暂停/状态过期/后台/Reduce Motion停止。沿用首页唱片比例，不改变首页3D。
- 尺寸按可用屏幕宽高收敛；小屏或长文字可竖向滚动。模糊只处理本页封面图片，ClipRect有界，未对GLB原生视图做背景采样。无封面或图片失败显示音符和暗色渐变，不伪造专辑内容。
- 曲名/歌手、车机状态、进度、上一曲/播放暂停/下一曲、循环、车机软件音量。标题及封面均来自既有currentTrack，播放数据来自车机快照；未知进度显示--:--、未知音量显示未知，相关控件禁用。
- 进度与音量只在松手时提交；循环依据真实模式all→one→off→all切换。复用原sendCommand、command_id、鉴权与执行状态，不把已提交或ack当起播/已执行，不通过本地动画改写播放进度。
- “更多”保留原详细状态面板、停止、随机播放、刷新、执行结果查询；主界面仅显示必要反馈。列表图标为“选择音乐”，打开既有喜欢列表，不假称获得车机队列；顶部选项仍可搜索。
- 歌词按钮仅在曲目提供网易云ID时允许读取既有接口，兼容冻结schema的字符串lrc及旧嵌套格式，显示普通文本歌词，非逐字同步。会话或曲目切换后丢弃旧展示，错误/空歌词明确提示。没有可用ID时禁用，不自动请求所有歌词。
- 喜欢与音质操作目前没有相应完整后端/车机能力，图标禁用并有提示，不假装已喜欢或已切换音质；不新增like/unlike或改变播放资源。

## 验证与边界

111项本地测试通过，flutter analyze无问题。新增覆盖320/430逻辑像素宽布局及无命令副作用、未知状态禁用、真实进度格式、音量连续拖动只松手提交一次且不改写真实音量、字符串歌词成功与HTTP403失败。既有登录/收藏/导航确认/抽屉/玻璃底栏/3D相关回归保持。3个个人签名文件哈希保持。

真机验收入口tool/immersive_player_acceptance.dart只进入播放页、查看控件、滚动、展开更多和返回，不触碰任何播放/进度/音量/循环操作，不发导航或账号写请求。截图及布尔JSON仅存忽略目录private/evidence/player-0.5.7/，不加入Git，不含公开账号、设备ID或域名记录。

未验收：本轮不发送真实控制命令，不能据此声称车机实际音频输出/seek/音量/循环端到端复测完成。当前实际状态无有效封面，真实封面下载及歌词请求未在生产触发，画面使用占位，不能把本地歌词mock成功称为生产可用。旋转、音质、喜欢等未支持/未实测边界如上。
