# 收藏列表与Plus Code新增验证

日期：2026-10-19。准备版本：0.5.4+22。当前手机稳定版仍为0.5.3+21；生产联调与覆盖安装等待后端修正和产品经理确认。客户端提交仅在本地保存，暂不推送依赖未冻结接口的改动。

## 客户端改动

- “全部”只列分类文件夹及未分类地址，不再重复列出文件夹中的地址。首次及后续分页均向后端请求 `folder_id=uncategorized`，不是只过滤手机已加载第一页；打开文件夹后继续按其ID分页。仅有文件夹时空态显示“暂无未分类地址”。
- 删除“输入目的地”按钮、输入弹窗和收藏抽屉中的手动解析面板。地图选点、搜索结果和收藏地址仍走明确确认后派发；保留这些路径需要的内部解析接口。地图卫星切换、抽屉上拉修复、左滑分类及玻璃底栏不变。
- 新增/编辑收藏的“显示地址”为选填，名称和显示地址均为空时用坐标作为可见标题，不伪造街道地址；保存与读取兼容空字符串，兼容服务端null响应归一化。
- 坐标输入与Plus Code输入二选一。完整码只解析为有效WGS84坐标后保存收藏；短码必须输入明确参考纬度/经度，可主动选择现有地图点作为参考，不自动采用GPS或城市名称。短码解析后另弹窗确认具体坐标，取消不保存。附带城市名不能绕过参考要求。
- 解析仅使用后端已声明的只解析契约；解析产生任务、缺少唯一候选、无效坐标/坐标系、旧后端不支持参考字段均停止。收藏保存不调用任务派发或音乐API，超时不自动重复新增。账号/域名切换的迟到结果丢弃。
