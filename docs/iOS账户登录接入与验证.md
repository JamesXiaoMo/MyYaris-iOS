2026-10-13（Asia/Tokyo），0.3.0+8。仅修改ios_app，不改backend/car_app或根契约。授权已由用户明确给出，因此根文档较早“尚未授权iOS接入”的描述不是当前限制。

## 当前交付

- 用户名/密码登录、普通注册入口、退出、启动时会话恢复、失效返回登录页。
- 正式设置不再有PHONE_TOKEN输入；显示用户名、昵称、头像、控车授权状态，可修改昵称并刷新权限。
- 登录成功不播放音乐、不发送导航。无控车授权时登录仍成功，显示需管理员绑定，停止播控WS/轮询，不自动请求bootstrap、提升角色或赋予车机权限。
- 收藏/行驶/音乐/首页3D固定pitch仅yaw、图标保留；已登录用户看到后端授权的数据范围，不自动迁移旧共享收藏。

## 会话与迁移边界

采用后端原生Bearer路径：login响应随机session_id作为内部凭据，HTTP/上传/音频探测与WSS用Authorization header；不把会话放URL，不选择Cookie模式、不存csrf_token，Dart客户端不维护Cookie会话。头像公开HTTPS单独加载，不附任何会话、不跟随重定向、最大2MB。

密码只用于本次提交，输入控件成功/失败后清空，不持久化、不日志输出。生产账号密码必须用户在手机自行输入；本轮没有创建生产普通账号或管理员，没有读取密码/Cookie/env，也没有发送bootstrap-admin或设备授权请求。

原Keychain `phone-session` 条目保持，正式初始化仅复用其域名/设备设置，不使用其中旧固定凭据认证。新增独立 `user-session-v1` 和 `connection-settings-v1` Keychain条目，仍使用本设备、仅解锁可读保护。退出注销后端会话、清本客户端动态会话，保留域名/设备配置、旧条目及服务器收藏，不退出网易云后台授权。

恢复先验证期限，再GET /auth/me核对真实身份、active与user/admin角色，不信任缓存的控车权限。网络故障不伪装恢复成功，也不删掉可能仍有效的缓存，可手动重试；401清会话/缓存/WS及轮询并回登录；403保留登录身份、标记当前车辆未授权并停止控车重连。WS重连先重新核对me；401/403握手或4401/4403/1008关闭分别检查会话/权限，不持续旧凭据重连。旧会话迟到回执不覆盖新账号状态，账号切换丢弃本地状态缓存与旧导航页面，防止跨账号残留显示。

后台暂停/前台恢复仍保留既有边界；到期不自动刷新密码或静态Token，重新登录。普通注册按后端校验；403或注册接口关闭时明确提示未开放。客户端没有管理员初始化和授权管理入口。

## 账号是什么 / 用户最少操作

1. 这是MyYaris后端账户登录。此次没有客户端默认用户名/默认密码，也没有我创建的生产账号。根文档的项目维护者只是API示例，不能当作已存在的账户。
2. 若已有后端账户，用户在手机输入自己的用户名与密码登录；不把密码发到聊天。
3. 若尚无账户，在手机点“注册普通账号”，自行设置用户名（3～32位字母、数字、_或-）和密码（8～128位），注册后登录。普通注册不成为管理员，也不自动获得控车。
4. 若需控车，由已有管理员给该用户授权car_p3pro，再在App设置点“刷新个人资料/权限”。若尚无首管理员，调度需让后端维护者确认并走受控初始化，密码由用户自己提供/设置；iOS不擅自创建或提权。
