# 交产品经理：MapKit与后端分类收藏协同需求

用户2026-10-18明确选择分类文件夹也保存后端，不接受仅本机分类。iOS负责MapKit主体、可拖拽底部收藏抽屉、搜索、加号新增地址/分类、文件夹右滑编辑/删除；地址选择或地图选点后仍显式解析与确认派发，不自动导航。

请调度后端工程师在backend实现SQLite账号隔离的文件夹增删改查，建议 /api/v1/favorite-folders；Favorite增加nullable folder_id，列表支持按folder_id查询（或客户端按响应字段筛选）。最终路径/字段以其维护契约为准，iOS不会把建议接口伪装已可用。需要确认：删除文件夹时地址移回未分类或拒绝非空，不默认删用户地址；普通用户只能自己的分类/地址，管理员也不能把别人的地址跨用户归类；重复名称、长度、父子层级（建议本轮单层）、删除确认、幂等/错误码及既有无folder_id兼容。地址仍使用WGS84；不修改网易云/车机。

请按用户分类后端同步授权调度实现及正常部署，回报最终契约/部署hash/测试，保留现有SQLite数据。iOS只改ios_app，不竞争backend/car与共享文档；无新接口前分类按钮明确显示待后端支持，不做静态/本机分类冒充同步。
