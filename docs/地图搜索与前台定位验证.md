# 地图搜索与前台定位（0.4.1+13）

检查日期：2026-10-18。仅修改 ios_app；保留签名、账号 Keychain、首页3D、玻璃底栏、音乐及收藏接口。

## 本次行为

- 行驶页右上角放大镜打开地点搜索。通过本机原生 `MKLocalSearch` 查询 Apple 地图地点/地址（例如麦当劳），使用当前地图区域作为搜索参考；最多展示20个候选，明确区分失败与无结果。
- 选择候选只更新地图标记和目的地坐标，并可将地点名/地址预填到新增收藏；不会保存收藏、发导航或播放音乐。导航仍需解析和用户明确确认。
- 地图首次创建时请求一次前台位置并居中；右下角定位按钮可再次请求。首次授权由用户在 iOS 系统弹窗处理。拒绝、超时或失败有可关闭提示，允许手动地图搜索；不把默认地图中心当作用户位置。
- 用户在定位等待期间手动移动地图/选择目标时，迟到的位置不会覆盖所选视野。不申请后台/Always定位；地图离开可见Tab或App后台时关闭蓝点持续更新，后台取消待完成请求。
- 抽屉圆角透明，地图延伸到圆角下24点；增加原生地图底部安全边距，保留 Apple Maps 与 Legal 归属。删除指定解释文字，导航确认逻辑保留。
- 搜索显式提交，不逐字请求；修改查询/退出会取消旧搜索，忽略迟到结果，校验坐标并去重。搜索及定位信息不写业务日志。
